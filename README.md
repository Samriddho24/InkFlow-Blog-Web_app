# InkFlow 📝

InkFlow is a simple blog web application built using Node.js, Express.js, EJS, HTML, CSS, and JavaScript. Users can create and view blog posts through a clean and responsive interface.

## 🚀 Features

* Create and publish blog posts
* View blog posts dynamically
* About page
* Contact page
* Responsive user interface
* Server-side rendering using EJS
* Dynamic routing with Express.js

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
* Node.js
* Express.js
* EJS

## ⚙️ How to Run

### Clone Repository

```bash
git clone <repository-url>
```

### Install Dependencies

```bash
npm install
```

### Start Server

```bash
node index.js
```

### Open Browser

```text
http://localhost:3000
```
